# Инструмент для сжатия текстовой информации

Данный проект предназначен для эффективного сжатия изображений, содержащих преимущественно текст, путём выделения текстовых областей, блочно-разреженного представления (BSR) и последующего сжатия методом LZMA или Gzip.

## Основная идея

1. **Детекция текста** – на изображении находятся прямоугольные области, содержащие текст (используется EasyOCR или OpenCV).
2. **Выделение текста** – из исходного изображения извлекаются только пиксели, принадлежащие тексту; фон заменяется чёрным.
3. **Подготовка к BSR** – изображение дополняется до размеров, кратных 16 (pad).
4. **Оптимальный размер блока** – обученная модель Random Forest предсказывает наилучший размер блока (от 4 до 20), делящий размеры изображения нацело.
5. **Блочно-разреженное представление** – матрица пикселей преобразуется в формат BSR (scipy.sparse.bsr_matrix).
6. **Сжатие** – BSR-представление сериализуется (через np.savez) и сжимается алгоритмами LZMA или Gzip вместе с заголовком (размеры, размер блока).

Декодирование восстанавливает изображение, позволяя визуализировать результат.

## Особенности

- Поддержка русского и английского языков (EasyOCR).
- Возможность выбора детектора текста: EasyOCR (более точный, но медленный) или OpenCV (быстрый, но менее точен).
- Автоматический подбор размера блока через машинное обучение (Random Forest) на основе признаков изображения.
- Сохранение сжатых данных в форматах `.xz` (LZMA) и `.gz` (Gzip).
- Визуализация результата: само декодированное изображение и spy-график ненулевых блоков.

## Использование

В папку проекта поместите изображение и переименуйте в `temp.jpg`.

Запустите Jupyter Notebook `visualisation.ipynb` – в нём пошагово показаны все этапы: детекция текста, извлечение, предсказание блока, сжатие и декодирование.

Пример кода для сжатия одного изображения:

```python
from image_transformation import detect_text_boxes, extract_text_only
from models.predictor import predict_block_size
from models.image_resizing import pad_to_multiple_of_16
from bsr_matrix import to_bsr
from compression import compress_matrix_lzma

# 1. Детекция и извлечение текста
image_path = "document.jpg"
boxes = detect_text_boxes(image_path)
text_img = extract_text_only(image_path, boxes)

# 2. Подгонка размеров под кратность 16
padded = pad_to_multiple_of_16(text_img)

# 3. Предсказание размера блока
block = predict_block_size(image_path)

# 4. Преобразование в BSR
bsr = to_bsr(padded, block)

# 5. Сжатие
compress_matrix_lzma(bsr, block, "compressed.xz")
```

### Декодирование

```python
from models.decoder import decode_compressed, visualize

img, b = decode_compressed("compressed.xz")
visualize(img, title="Восстановленное изображение")
```

### Пакетная обработка

Можно обработать все изображения в папке `Data` и сгенерировать CSV с оптимальными размерами блоков, запустив:

```bash
python process_dataset.py
```

После этого будет создан файл `optimal_blocks.csv`, который используется для обучения модели.

## Модель предсказания размера блока

- **Алгоритм**: Random Forest (sklearn).
- **Признаки**: более 20 характеристик изображения: плотность текста, количество контуров, средняя площадь контуров, горизонтальная/вертикальная структура, статистика яркости, сложность и др.
- **Целевая переменная**: оптимальный размер блока (найденный перебором по критерию сжатия или разреженности).
- **Обучение**: запуском `python models/trainer.py` (требуется наличие `optimal_blocks.csv` и папки `Data`).
- **Сохранённая модель**: `models/rf_block_predictor.pkl`.
